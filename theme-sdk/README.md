# SC4-ModernCamera Theme SDK

`reference` is the default SC4-ModernCamera skin exported under a separate
resource group. It is both an editable starting point and a load-order/fallback
test package.

Use `tools/build_sc4_ui_theme.py` to export a fresh template, validate it, and
build a standalone DAT. See `docs/ui-theme-contract.md` for the compatibility
rules and installation format.
